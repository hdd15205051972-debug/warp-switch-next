WARP 新开关 · Windows 版 1.0.0
================================

适用于 Windows 10（1803 或更新）和 Windows 11。非官方客户端，与 Cloudflare 无隶属关系。


安装
----
1. 把整个「WARP 新开关」文件夹放到一个固定的位置（例如「文档」或 D:\Apps）。
   core 文件夹必须和 WARP 新开关.exe 放在一起。
2. 双击「WARP 新开关.exe」。
   如果出现「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
3. 第一次点「同意条款并注册」：程序会向 Cloudflare 注册你自己的免费 WARP 账号，然后自动连接。
4. 显示「已连接」后，浏览器等使用系统代理的程序就能用了。


日常使用
--------
- 开启 / 关闭：点窗口中间的大按钮。
- 换入口重试：连不上时换一组入口再试。
- 修改伪装域名：点「伪装域名」那一行的「修改」，默认 www.bing.com。
- 连接模式：一般用「自动尝试」。
- 开机时自动连接：打开后，每次登录 Windows 都会在后台自动连接；
  睡眠唤醒、网络恢复后连接断了也会自动重连。手动点「关闭」后不会自动重连。
- 关掉窗口后程序仍在右下角通知区域运行（盾牌图标）。
  灰色 = 已关闭，蓝色 = 连接中，绿色 = 已连接，橙色 = 没连上。
- 退出：会先关闭连接、恢复原来的代理设置，再退出。


常见问题
--------
- 提示「系统正在使用另一个代理」：先关掉其他代理或翻墙软件，再点开启。
- 提示端口被占用：有别的程序在用 7891 或 18443 端口，关掉它再试。
- 一直连不上：点「换入口重试」，或换一个伪装域名，或把连接模式改成另一种。
  也可以点「打开日志」，查看 worker.log 和 connection.log。
- 杀毒软件拦截 core 文件夹里的 usque：这是开源的连接内核，需要放行它才能连接。


卸载
----
1. 在程序里关掉「开机时自动连接」，然后点「退出」。
2. 删除「WARP 新开关」文件夹。
3. 在资源管理器地址栏输入 %LOCALAPPDATA%\WarpSwitchNext 并删除这个文件夹（里面是你的账号和日志）。


隐私
----
账号和日志只保存在本机 %LOCALAPPDATA%\WarpSwitchNext。
连接内核 usque 4.2.1 保持服务器公钥校验开启。
更换入口、伪装域名或分片方式，不能保证所有网络都能连接。请遵守适用的网络使用规则。
