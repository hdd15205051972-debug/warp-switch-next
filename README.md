# WARP 新开关 · Windows 版

一个轻量的 Windows 图形界面客户端，通过 Cloudflare WARP / MASQUE over HTTP/2 连接网络。一键开启或关闭，可切换入口、修改伪装域名（SNI），并可尝试 TLS 握手分片。

**适用于 Windows 10（1803 或更新）和 Windows 11，支持 x64、ARM64 和 32 位系统。** 使用 Windows 自带的 .NET Framework，无需另装运行库。此项目为非官方客户端，与 Cloudflare 无隶属关系。

macOS 版在本仓库的 [`main` 分支](https://github.com/hdd15205051972-debug/warp-switch-next/tree/main)。

## 下载和安装

下载 `WARP-Switch-Next-Windows-1.0.0.zip`。

1. 解压，把「WARP 新开关」文件夹放到一个固定的位置（例如「文档」或 `D:\Apps`）。打开开机自动连接后不要再移动它。
2. 双击 `WARP 新开关.exe`。程序没有代码签名，Windows 可能提示「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
3. 首次点击「同意条款并注册」，程序会向 Cloudflare 注册属于你自己的免费 WARP 账号，然后连接。
4. 看到「已连接」后，Edge、Chrome 等浏览器和使用系统代理的程序即可使用。

## 日常使用

- **开启 / 关闭**：验证实际 WARP 流量成功后才启用系统代理；关闭时恢复原来的代理设置。
- **换入口重试**：跳过上次成功的入口，重新尝试其他候选入口。
- **修改伪装域名**：点「伪装域名」一行的「修改」；默认 `www.bing.com`。SNI 改变不会把 Cloudflare 的入口 IP 变成另一家网站的 IP。
- **连接模式**：「自动尝试」先用 TLS ClientHello 记录分片，再尝试不分片的兼容模式；也可手动固定其中一种。
- **开机时自动连接**：打开后，登录 Windows 时程序在任务栏通知区域（右下角）后台启动，等网络就绪后自动连接。电脑睡眠唤醒或网络恢复时，如果连接已经中断，也会自动重新连接；连接失败会隔一段时间（30 秒起，最长 5 分钟）再试。手动点「关闭」后不会自动重连，直到你再次开启。
- **通知区域图标**：盾牌颜色表示状态（灰色已关闭、蓝色连接中、绿色已连接、橙色未连上）。关掉窗口后程序仍在后台运行，点图标可重新打开窗口；「退出」会先关闭连接并恢复代理。
- **打开日志**：打开数据文件夹，里面的 `worker.log`、`connection.log` 记录了连接过程。

## 系统代理如何设置

连接时，程序把当前用户的 Windows 代理（「设置 → 网络和 Internet → 代理」）设为 `127.0.0.1:7891`，并保留原有的绕过规则，同时让本地地址和常用内网地址直连。Windows 会优先使用「自动检测设置」和「使用设置脚本」，所以这两项在连接期间会暂时关闭，关闭连接时原样恢复。

- 修改前会先把原设置保存到磁盘。程序意外退出、电脑断电后，下次打开程序时会自动恢复。Windows 注销或关机时也会先恢复。
- 如果系统已经在用其他代理软件，程序会拒绝连接并提示，不会覆盖。
- 如果你在连接期间手动改了代理，关闭连接时会保留你的改动。
- 不遵循系统代理的程序（部分游戏、微软商店应用等）不经过 WARP。

## 隐私和服务器验证

安装包不含共享账号、私钥、令牌或个人配置。每位使用者单独注册自己的账号。

账号和日志仅保存在本机 `%LOCALAPPDATA%\WarpSwitchNext\`。向 Cloudflare 注册和传输流量受其[服务条款](https://www.cloudflare.com/terms/)约束。

连接内核为 **usque 4.2.1**（`core` 文件夹），保持服务器公钥校验开启，不传入 `--insecure`。握手分片只改变 TLS 记录边界，不改变握手内容，也不解密隧道。本地转发和代理只监听 `127.0.0.1`，局域网里的其他设备无法使用。

更换入口、SNI 或分片方式不能保证所有网络均可连接，也不能保证网络设备无法识别 WARP。请遵守适用的网络使用规则。

## 卸载

1. 在程序里关掉「开机时自动连接」，再点「退出」。
2. 删除「WARP 新开关」文件夹，以及 `%LOCALAPPDATA%\WarpSwitchNext`（在资源管理器地址栏输入这个路径即可打开）。

## 从源码构建

需要 Windows 和 .NET SDK（6 或更新）。

```powershell
git clone -b windows https://github.com/hdd15205051972-debug/warp-switch-next.git
cd warp-switch-next
./build.ps1
```

构建脚本从 usque 官方 GitHub Release 下载固定版本的 x64、ARM64 和 32 位程序，核验固定的 SHA-256，再编译。输出为 `dist/WARP 新开关/` 和 zip 安装包。依赖二进制不存放在源码仓库。

## 测试

每次推送都会在 GitHub 的 Windows 电脑上自动编译并运行：

- `--self-test`：TLS 分片与重组、部分读取与尾随记录、域名校验、代理规则、设置和账号文件（不改动电脑任何设置，可在本机运行）。
- `--proxy-test`：设置并恢复系统代理，包括自动检测、设置脚本、已有其他代理、连接期间用户改动、崩溃后恢复等情况。
- `--screenshots`：渲染窗口在各状态下的截图。
- `--connect-test`：真实注册 WARP 账号，用两种连接模式分别连通，再通过系统代理访问网页并验证经过 WARP，最后确认代理已恢复。
